# 01. Usuarios

En este módulo administras las cuentas que pueden usar **GMAS Visitas Sociales**.

## Objetivo

Crear, actualizar y controlar usuarios según su rol y empresa asignada.

## Pantallas y funcionalidad

### 1) Búsqueda y listado de usuarios

![Usuarios - Búsqueda](/img/AplicacionWeb/01.Usuarios/07.Usuarios_Buscador.png)

Qué puedes hacer:

- Buscar usuarios por nombre, correo o estado.
- Revisar estado de acceso.
- Entrar a acciones rápidas por registro.

### 2) Asignar empresa al usuario

![Usuarios - Asignar empresa](/img/AplicacionWeb/01.Usuarios/08.Usuarios_Asignar_Empresa.png)

Define en qué empresa puede trabajar cada usuario.

### 3) Cambio de contraseña por administración

![Usuarios - Cambiar contraseña](/img/AplicacionWeb/01.Usuarios/09.Usuarios_Cambiar_contraseña.png)

Uso recomendado:

- Restablecer contraseña cuando el usuario no puede ingresar.
- Forzar cambio en el siguiente inicio de sesión.

### 4) Edición de usuario

![Usuarios - Editar](/img/AplicacionWeb/01.Usuarios/10.Usuarios_Editar.png)

Actualiza datos personales, rol y estado del usuario.

### 5) Eliminación de usuario

![Usuarios - Eliminar](/img/AplicacionWeb/01.Usuarios/11.Usuarios_Eliminar.png)

:::warning Recomendación
Antes de eliminar, valida dependencias del usuario en visitas, auditoría y reportes.
:::

### 6) Administración general

![Usuarios - Administración](/img/AplicacionWeb/01.Usuarios/12.Usuarios_Administración.png)

## Flujo sugerido

1. Buscar si el usuario ya existe.
2. Crear usuario.
2. Asignar empresa.
3. Definir rol y permisos.
4. Validar ingreso del usuario.
