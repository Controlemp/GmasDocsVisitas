# 09. Aplicación

Este módulo define el contexto operativo inicial del usuario dentro del sistema.

## Objetivo

Permitir seleccionar empresa y navegar de forma clara a cada módulo.

## Pantallas y funcionalidad

### 1) Selección de empresa

![Aplicación - Seleccionar empresa](/img/AplicacionWeb/09.Applicacion/02.Seleccionar_Empresa.png)

Define la empresa sobre la que trabajará el usuario en su sesión.

### 2) Menú principal

![Aplicación - Menú](/img/AplicacionWeb/09.Applicacion/06.Menu.png)

Permite navegar a los módulos de operación y administración según permisos.

## Flujo sugerido

1. Iniciar sesión.
2. Seleccionar empresa.
3. Ingresar al módulo requerido desde el menú.
