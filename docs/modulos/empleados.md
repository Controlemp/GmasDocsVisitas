# 03. Empleados

En este módulo gestionas los colaboradores que participan en visitas sociales.

## Objetivo

Mantener actualizado el padrón de colaboradores para asignación y seguimiento de visitas.

## Pantallas y funcionalidad

### 1) Búsqueda de empleados

![Empleados - Búsqueda](/img/AplicacionWeb/03.Empleados/14.Lista_Empleados_Buscador.png)

Qué puedes hacer:

- Buscar colaboradores por filtros disponibles.
- Revisar estado del registro.
- Acceder a editar o eliminar.

### 2) Edición de empleado

![Empleados - Editar](/img/AplicacionWeb/03.Empleados/14.Lista_Empleados_Editar.png)

Permite actualizar datos del colaborador para mantener información vigente.

### 3) Eliminación de empleado

![Empleados - Eliminar](/img/AplicacionWeb/03.Empleados/14.Lista_Empleados_Eliminar.png)

Permite retirar registros cuando no se requiere operación futura.

## Flujo sugerido

1. Buscar colaborador.
2. Actualizar información si aplica.
3. Eliminar solo si no tiene visitas en proceso.
