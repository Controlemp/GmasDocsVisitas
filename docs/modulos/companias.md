# 02. Compañías

En este módulo administras las empresas que operan en **GMAS Visitas Sociales**.

## Objetivo

Registrar y mantener actualizada la información de cada compañía.

## Pantallas y funcionalidad

### 1) Búsqueda de compañías

![Compañías - Búsqueda](/img/AplicacionWeb/02.Compañias/13.Lista_Compañias_Buscador.png)

Qué puedes hacer:

- Localizar compañías por nombre o código.
- Validar estado (activa/inactiva).
- Entrar a editar o eliminar.

### 2) Edición de compañía

![Compañías - Editar](/img/AplicacionWeb/02.Compañias/13.Lista_Compañias_Editar.png)

Campos que debes mantener al día:

- Datos generales de identificación.
- Información de contacto.
- Estado de activación.

### 3) Eliminación de compañía

![Compañías - Eliminar](/img/AplicacionWeb/02.Compañias/13.Lista_Compañias_Eliminar.png)

:::warning Importante
Antes de eliminar una compañía, confirma que no tenga usuarios, visitas o asignaciones activas.
:::

## Flujo sugerido

1. Buscar compañía.
2. Validar datos actuales.
3. Editar o inactivar según necesidad.
4. Eliminar solo si no tiene operación asociada.
