# 08. Seguridad

Este módulo administra el acceso a la plataforma.

## Objetivo

Garantizar que solo usuarios autorizados ingresen al sistema.

## Pantalla principal

### 1) Inicio de sesión

![Seguridad - Login](/img/AplicacionWeb/08.Seguridad/01.Login.png)

Qué puede hacer el usuario:

- Ingresar con credenciales asignadas.
- Acceder a su contexto de trabajo según permisos.

## Recomendaciones

- Verificar usuario y contraseña antes de reintentar.
- Reportar bloqueo o acceso no autorizado al administrador.
