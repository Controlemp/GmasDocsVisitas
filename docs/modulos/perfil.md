# 05. Perfil

En este módulo cada usuario administra su información personal y su contraseña.

## Objetivo

Mantener datos de usuario actualizados y proteger el acceso a la cuenta.

## Pantallas y funcionalidad

### 1) Información personal

![Perfil - Información personal](/img/AplicacionWeb/05.Perfil/01.Informacion_Personal.png)

Desde esta pantalla se puede:

- Consultar datos de cuenta.
- Actualizar información de contacto.
- Ver información de la cuenta.

### 2) Cambio de contraseña

![Perfil - Cambiar contraseña](/img/AplicacionWeb/05.Perfil/02.Cambiar_Contraseña.png)

Recomendaciones:

- Usar una contraseña robusta.
- Evitar reutilizar contraseñas previas.
- Cambiarla de forma periódica.

## Flujo recomendado

1. Revisar datos personales.
2. Corregir información desactualizada.
3. Actualizar contraseña cuando aplique.

:::tip Seguridad
Realiza el cambio de contraseña desde un dispositivo de confianza y cierra sesión al finalizar.
:::
