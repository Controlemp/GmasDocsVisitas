# Configuración y Seguridad

Esta sección describe las pantallas de autenticación y opciones generales de aplicación en GMAS Visitas.

## Inicio de sesión

![Seguridad - Login](/img/AplicacionWeb/08.Seguridad/01.Login.png)

En el acceso inicial se valida:

- Usuario y contraseña.
- Políticas de acceso.
- Estado de cuenta.

## Selección de empresa

![Aplicación - Seleccionar empresa](/img/AplicacionWeb/09.Applicacion/02.Seleccionar_Empresa.png)

Una vez autenticado, el usuario define el contexto operativo de trabajo.

## Menú principal de aplicación

![Aplicación - Menú](/img/AplicacionWeb/09.Applicacion/06.Menu.png)

Desde el menú se accede a módulos de operación, administración y consulta.

## Recomendaciones administrativas

- Revisar permisos por perfil.
- Mantener políticas de contraseña activas.
- Restringir acceso a usuarios inactivos.
